# sars-cov-2-phylogeny

> **Nota para los usuarios:** Los resultados finales de la ejecución de este pipeline (el árbol filogenético `.treefile` y la gráfica de control de calidad `.pdf`) se guardarán automáticamente dentro de la carpeta `results/`. Esta carpeta se genera localmente al ejecutar el código y está ignorada por Git para evitar subir archivos pesados al repositorio.
